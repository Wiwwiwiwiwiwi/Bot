# 🤖 Railway 3x-ui Bot

ربات تلگرامی که **کل فرایند راه‌اندازی 3x-ui چند-ریجن روی Railway** را خودکار انجام می‌دهد.

## ✨ امکانات

| مرحله | کار |
|---|---|
| ۱ | دریافت توکن Railway (چند اکانت قابل ثبت است) |
| ۲ | ساخت پروژه + ۴ سرویس (xui-nl/sg/us-va/us-ca) با دامنه — **بازیافت پروژه/سرویس ناقص قبلی** |
| ۳ | راهنمای تنظیم ریجن (کاربر در داشبورد تنظیم می‌کند) |
| ۴ | اتصال نودها به پنل مرکزی |
| ۵ | ساخت اینباند VLESS+Reality (کلید مشترک — ۴ در، ۱ قفل) |
| ۶ | TCP proxy + روتیت به دامنه خوب + Host ها (idempotent) |
| ۷ | تحویل لینک‌های اتصال با UUID کاربر |

**امکانات اضافه:**
- 👥 **مدیریت چند اکانت** — افزودن / سوییچ / حذف (هر اکانت state جدا دارد)
- 🌐 **چرخش TCP Proxy بعد از ستاپ** — هوشمند (۱۲ دامنه تأیید) یا رندوم؛ همه ریجن‌ها یا تک‌ریجن؛ نمایش زنده + دکمه 🛑 توقف + سقف زمانی
- 🧹 **/cleanup** — پاک کردن پروژه‌های تستی از داخل چت
- 💾 **پایداری state** — ذخیره روی ولوم `/data` (بعد از ری‌استارت همه‌چیز سر جایش است)
- 🔒 **وایتدلیست UID** — فقط کاربران مجاز (`ALLOWED_UID`)
- 🔗 **بازسازی لینک‌ها بعد از چرخش** — دکمه «ساخت لینک جدید»
- 📊 **پیام‌های progress زنده** — ربات هنگام اجرای اسکریپت‌ها قفل نمی‌شود (async)

## 🚀 اجرا روی Railway

1. **ساخت ربات تلگرام:** با [@BotFather](https://t.me/BotFather) ربات بساز و توکن را کپی کن.
2. **دیپلوی:** `New Project → Deploy from GitHub repo` → ریپو `Kolkolz/railway-bot`
3. **متغیر محیطی الزامی:**
   ```
   BOT_TOKEN=توکن_ربات_تلگرام
   ```
4. **استفاده:** `/start` → توکن Railway بفرست → `🚀 شروع Setup` → تنظیم ریجن در داشبورد → `/continue`

> 💡 برای پایداری state یک **ولوم** به سرویس ربات اضافه کن (mount path: `/data`) —
> بدون ولوم، state با هر ری‌استارت پاک می‌شود.

## 🛠 متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `BOT_TOKEN` | — | توکن ربات تلگرام (الزامی) |
| `ALLOWED_UID` | خالی (همه) | وایتدلیست Telegram user IDs (کاما جدا) |
| `STATE_FILE` | `/data/state.json` | مسیر فایل state (روی ولوم) |
| `LOG_DIR` | `/data/logs` | لاگ سشن‌ها |
| `STARTUP_DELAY` | `20` | ثانیه صبر قبل از polling (کاهش 409) |
| `ROTATE_TIMEOUT` | `1500` | سقف زمانی چرخش TCP (ثانیه) |
| `STATE_SECRET` | خالی (بی‌رمز) | 🔐 کلید Fernet برای رمزنگاری توکن‌های Railway در فایل state — دیدن بخش امنیت |
| `XUI_USERNAME` / `XUI_PASSWORD` | `admin` / `admin` | کد پنل 3x-ui |
| `REPO` | `Kolkolz/3xui-multi-region` | ریپوی سرویس‌ها |

## 🔐 امنیت (رمزنگاری state)

به‌صورت پیش‌فرض توکن‌های Railway در `state.json` **به‌صورت متن ساده** ذخیره می‌شوند
(چون هر کسی که به ولوم دسترسی دارد می‌تواند آن‌ها را بخواند).

برای رمزنگاری آن‌ها هنگام ذخیره روی دیسک، یک `STATE_SECRET` تنظیم کن:

```bash
# ساخت کلید (یک بار — همان مقدار را در Railway نگه دار)
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
# → مثلاً: 4Vc...Q=
```

سپس مقدار خروجی را در متغیر محیطی `STATE_SECRET` بگذار. بعد از ری‌استارت، ربات
توکن‌ها را با همان کلید رمزگشایی می‌کند. اگر کلید گم شود، اکانت‌های ذخیره‌شده قبلی
قابل استفاده نیستند (توکن‌ها را دوباره وارد کن) — کلید را جایی امن نگه دار.
بدون `STATE_SECRET` رفتار قبلی (متن ساده) حفظ می‌شود و همه‌چیز به‌روال قبل کار می‌کند.

## ⚠️ نکات

- **سقف ۲۵ سرویس/روز** برای اکانت‌های جدید Railway — ربات پروژه/سرویس‌های ناقص را بازیافت می‌کند تا سهمیه هدر نرود
- ریجن‌ها توسط کاربر تنظیم می‌شوند — ربات سرویس‌ها را بدون ریجن می‌سازد
- TCP proxy ها به دامنه‌های لیست خوب (monorail, nozomi, ...) روتیت می‌شوند
- بعد از هر چرخش پروکسی، لینک‌های قبلی نامعتبرند — از دکمه «ساخت لینک جدید» استفاده کن
